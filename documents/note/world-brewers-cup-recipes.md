コーヒーの淹れ方を調べていると、必ず「世界チャンピオンのレシピ」に行き当たります。
20g / 300g / 92℃ ——数字は出てくるのですが、なぜその数字なのかまでは書かれていないことが多い。

Bean Tracker のレシピタブに、World Brewers Cup の過去11大会ぶんの優勝レシピを並べています。
11杯を横に並べてみると、流行の移り変わりと、共通していることがはっきり見えてきました。

---

## 1. 「蒸らして数回に分けて注ぐ」は、もう当たり前ではない

2015年の優勝（Odd-Steinar Tøllefsen / ノルウェー）は、V60・20g・300g・92℃、蒸らし45秒で総抽出3分30秒。
教科書のような淹れ方です。

ところが近年の優勝レシピは、そもそも形が違います。

- **2018年 Emi Fukahori（スイス）** — GINA で浸漬と透過を切り替え、80℃ → 95℃ → 80℃ と温度を3段階に振る
- **2022年 Shih Yuan Hsu（台湾）** — 1投目だけ70℃、残り3投は95℃。挽き目も1000μmと800μmを混ぜる
- **2026年 Nas Jaafar（マレーシア）** — 前半は透過、58秒でスイッチを閉じて後半は浸漬

「1つのやり方を丁寧にやる」から、**「途中で条件を変える」**へ移ってきている。
温度を1つに決めない、挽き目を1つに決めない、浸漬か透過かも1つに決めない。

## 2. 使う豆は、ほぼゲイシャ。ただし例外がおもしろい

11大会のうち大半がゲイシャ（Geisha / Gesha）です。パナマ、コロンビア、エチオピア。
そのなかで、あえて外した回が2つあります。

- **2023年 Carlos Medina（チリ）** — コロンビアの **シドラ**。ゲイシャで正面から張り合うのを避けたと語っています。ラテンアメリカ勢として初の優勝
- **2021年 Matt Winton（スイス）** — **ユーゲニオイデス** という珍しい種を Catucai と混ぜたブレンド。カフェイン量が少なく、砂糖のような甘さが出る種です
- **2018年 Emi Fukahori** — ブルボンの突然変異種 **ラウリーナ**

勝ち筋が「いちばん良いゲイシャを持ってくる」だけではない、ということです。

## 3. 水の話が、思ったより多い

数字を見ていると見落としますが、優勝者は水を選んでいます。

- **2015年** ノルウェー西海岸の天然水。ミネラルが少なく、口当たりが柔らかいものを選んだと明言
- **2019年 Jia Ning Du（中国）** カルシウム4ppm / マグネシウム15ppm と、組成まで指定
- **2024年 Martin Wölfl（オーストリア）** 抽出用に組成を調整した水（Apax）

家庭で真似るなら、まず軟水のミネラルウォーターに替えてみるだけでも変わります。

## 4. 道具は「速く落とす」方向に進んでいる

- **2024年** Orea V4（平底）＋ Sibarist の抜けの速い紙。**細挽き630μmでも詰まらせずに落としきる**組み合わせ
- さらに **Melodrip**（注湯の勢いを殺す道具）で、湯を面で落として粉を掘らない

細かく挽けば成分は出やすいが、詰まると渋くなる。
そこを**紙と器具の抜けの速さで解決する**、というのが最近の作り方です。

## 5. 家で再現するなら、数字ではなく「動かし方」を持ち帰る

11杯を並べて、いちばん役に立ったのはここでした。

| 動かすもの | どちらへ動くか |
| --- | --- |
| 比率 | 1:15 は濃く、1:17 は軽い。まず 1:16 から |
| 湯温 | 高いほど早く出る。浅煎りは93〜96℃。渋ければ下げる |
| 挽き目 | 細かいほど濃い。落ちきる時間が予定より長ければ粗く |
| 注ぐ回数 | 回数が多いほど濃く出る。総量が同じでも3回に分ければ濃い |
| 前半の配分 | **4:6メソッド**では最初の40%（2投）で方向が決まる。1投目を少なくすると甘く、多くすると明るい |

最後の行は、2016年優勝の **粕谷哲**さんが考案した 4:6メソッドの考え方です。
湯温・挽き目・間隔を固定して、**投の量だけで味を動かす**。だから再現できるし、人に教えられる。
世界大会のレシピのなかで、家庭にいちばん降りてきた1つだと思います。
